# Original observations and calculation checks

[reservations.csv](reservations.csv) labels three fitting observations and one withheld observation. They are invented and contain no student or customer data. [check-algebra.py](check-algebra.py) checks the worked calculations independently using only Python's standard library. From the repository root, run:

```sh
python3 examples/check-algebra.py
```

The tests check these small fixtures, not classroom outcomes. [Worksheet](../practice/worksheet.md)
